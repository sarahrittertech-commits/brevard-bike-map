# Bike Brevard Map

A hyperlocal mobile app that answers one question: **how do I get from here to
there in Brevard, on a bike, without ending up on a road I don't want to be on?**

## Why this project exists

Brevard is a cycling town with a greenway and a lot of places worth riding to.
What it doesn't have is an obvious answer to "can I bike from the brewery to
the pool, and how?" General-purpose tools like Google Maps' bike layer and
Strava answer that badly for a town this size, because they don't know which
local connections riders actually use.

## What this project is for

This app is **proof of work**. It is the September 2026 entry for the Women in
AI group challenge, and it exists to demonstrate that PushPopDev ships finished
things on a deadline.

That framing drives every scope decision on this project:

- It is deliberately small. Two weeks of part-time work, not a platform.
- It is **not** a prototype for the women's outdoor community app. Shared code
  between the two is explicitly a non-goal.
- It is not designed to be monetised. There is no business model and that is
  fine.
- Done and shipped beats complete. A short, finished app is the deliverable.
